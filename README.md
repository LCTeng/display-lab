# 顯示器導論觀念實驗室

以「顯示器導論特別記憶」筆記整理的互動式觀念網站（純靜態 HTML／CSS／JavaScript，不需建置）。

## 主題
1. 人眼與光度學
2. 色度學與色域
3. 對比與閃爍
4. 視角與多域（量測座標、多域 VA、四域到八域、IPS／FFS）
5. Frank 彈性與 Fréedericksz 轉變
6. 背光光學膜（BEF、DBEF）
7. 驅動與矩陣定址
8. 畫素電路（1T1C、2T1C、LTPO）

## 檔案
- `index.html`：入口頁
- `css/style.css`：樣式
- `js/cmf-data.js`、`js/vision-data.js`：CIE 1931 配色函數、V′(λ) 與 LMS 錐狀細胞資料
- `js/engine.js`：色度、偏光光學、液晶與靜電場計算
- `js/ui.js`、`js/pages.js`：各主題頁面
- `js/main.js`：路由與啟動

本機預覽：直接用瀏覽器開啟 `index.html` 即可。
